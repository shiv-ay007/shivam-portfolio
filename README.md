# Abhay Vishwakarma — Portfolio

A personal portfolio built with **React + Vite**, **Tailwind CSS**, and **react-icons**.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

Output goes to the `dist/` folder — deploy it to Netlify, Vercel, or any static host.

## Structure

```
src/
  components/
    Navbar.jsx
    Hero.jsx
    About.jsx
    Skills.jsx
    Projects.jsx
    Experience.jsx
    Contact.jsx
    Footer.jsx
  App.jsx
  index.css
  main.jsx
```

## Things to personalize before publishing

- `src/components/Contact.jsx` — real email, GitHub, LinkedIn links
- `src/components/Projects.jsx` — swap in your real project links and screenshots
- `src/components/Experience.jsx` — update dates/roles as needed
- Add a `resume.pdf` to the `public/` folder (linked from the Hero section)
- `index.html` — meta description / title if you want to tweak SEO copy
